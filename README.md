## Что это за программа?
Это приложение с главным меню, из которого можно открыть 8 разных заданий. Каждое задание — это отдельное окошко, сделанное в программе Visual Studio на языке C#.

---

## Как запустить
1. Откройте файл с проектом (`.sln`) в Visual Studio.
2. Нажмите клавишу **F5** (или зеленую кнопку «Пуск» вверху).
3. Откроется главное меню. Нажимайте на кнопки, чтобы проверить, как работают задания.

---

## Что было сделано в каждом задании:

**1. Игра «Угадай число»**
Программа загадывает число. Пользователь вводит свои варианты, а программа пишет «больше» или «меньше». Считает количество попыток. Кнопка «заново» начинает игру с нуля.

**2. Случайный цвет**
При нажатии на кнопку фон формы меняется на случайный цвет. Для этого использовался `Random` и функция смешивания цветов RGB (`Color.FromArgb`).

**3. Вывод текста (MessageBox)**
Пользователь пишет текст в поле, нажимает кнопку, и этот текст выскакивает в окошке `MessageBox.Show()`.

**4. Изменение текста на кнопках**
В поле ввода пишется текст. Когда нажимаешь на любую из кнопок, её название меняется на этот текст.

**5. Скрытые надписи (Visible)**
При запуске окна все надписи (Label) спрятаны (`Visible = false`). При нажатии на определенные кнопки нужная надпись появляется.

**6. Блокировка поля**
Две кнопки: одна делает текстовое поле неактивным (в него нельзя писать), другая — снова активным (свойство `Enabled`).

**7. Заметки (Работа с файлами)**
Можно написать текст в большое поле и сохранить его на компьютер (кнопка «сохранить» через `SaveFileDialog`). А потом загрузить этот файл обратно в программу (кнопка «загрузить» через `OpenFileDialog`).

**8. Калькуляторы (два варианта)**
*   *Вариант 1 (четыре поля):* Вводим число, знак действия и второе число. Нажимаем «рассчитать» и получаем ответ.
*   *Вариант 2 (как на телефоне):* Кнопки с цифрами и знаками действий. 
В обоих калькуляторах использовались дробные числа (`double`). Чтобы программа не вылетала, если ввести буквы вместо цифр, сделана проверка (`TryParse`). Также добавлена защита от деления на ноль (программа пишет ошибку, а не ломается).
